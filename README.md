# flask-website
basic flask website made in python with flask framework for web-dev class 

## Run locally

Requires Python 3.9+.

```
python -m venv venv
venv\Scripts\activate        # Windows  (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000
